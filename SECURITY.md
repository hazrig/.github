# Security Policy

## Reporting a vulnerability or data exposure

If you find a security issue, leaked credential or exposed personal data in any Activation Greenhouse Ltd repository, **do not open a public issue**.

Email [security@activationgreenhouse.com](mailto:security@activationgreenhouse.com) with:

- The repository and file or commit affected.
- What was exposed and how you found it.
- Any steps to reproduce.

We aim to acknowledge reports within 2 working days and will keep you updated until it is resolved.

## Handling client data

AGL processes client data under UK GDPR. Any suspected personal data breach is assessed within 24 hours so that the client (as controller) can meet the 72-hour ICO notification window where required.
